# 论文视频讲解

只提供论文 PDF 即可开始。默认用中文从研究问题和一个具体例子讲起，沿主图解释方法，逐步拆解关键公式，再对照实验、消融和局限。每章安排至少一个随看随问条目。已有旁注、聊天记录和本次指示时，将其融入对应章节。

1. 读取论文和用户指定的前序聊天、旁注、讲稿与参考视频。以用户当次写的讲解思路定章节顺序、深度、时长和术语。保留之前理解中有价值的例子，遇到冲突时回到原文核对。
2. 为每章编排屏幕要点、逐段中文口语旁白和常见追问。标明 PDF 页码、图表或公式编号，必要时从原文裁取图表，或制作注明为示意的讲解图。可以按研究动机、任务设定、方法流程、公式例子、实验与局限组织，具体顺序随用户思路调整。
3. 用户要求提出新研究方向时，检索近期相关顶刊、顶会和预印本，对照最接近的工作，记录日期、来源、区别及可运行的验证实验。只有检索范围内无直接匹配时，才描述为待验证的候选方向。
4. 参考插件目录的 [README](../../README.md) 生成分镜 JSON，使用安装了插件 `requirements.txt` 所列依赖的 Python 执行 `scripts/render.py`，导出 MP4、字幕和互动播放器。脚本路径相对于本技能目录。Windows 默认使用简体中文 SAPI。用户已有逐段 WAV 时用 `--audio-dir`。分镜与来源定位信息留在项目中，便于复查或重渲染。
5. 检查视频画面和音轨、字幕起止、章节跳转、已覆盖问题和未匹配问题。交付播放器入口和 MP4。播放器的离线回答来自生成时编写的问答条目，可按章节补充。
